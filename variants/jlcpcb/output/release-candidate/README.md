# JLC-3 controlled prototype

Upload the matching `gerbers-and-drills.zip`, `bom/jlc-smt-bom.csv` and
`assembly/jlc-smt-cpl.csv` to JLCPCB. See `READINESS.json` and
`docs/PROTOTYPE_JLC3.md` for build scope, settings and first-article checks.
Through-hole/manual parts and hardware are listed separately in `bom/`.
Editable KiCad 10 sources, libraries and models are in `cad/`.
This package supports building a test prototype; physical qualification remains to be performed.
